## 🏛️ Overview

Welcome to the personal portfolio repository of **Sara Khalifa Abdelnour**. This website is built with a **Modern Egyptian Pharaonic & Royal Gold Theme**, crafted specifically for software recruiters, enterprise engineering managers, and technical teams.

It highlights practical software development experience across **full-stack .NET application engineering** at *Wadi Degla Clubs* and **Microsoft Dynamics 365 CRM solution customization** at *Ejada Systems*.

---

## ✨ Key Features

- **🏛️ Modern Pharaonic Theme**: Custom royal palette featuring Egyptian Royal Gold, Lapis Lazuli, Sandstone Papyrus light theme, and Obsidian Granite dark slate mode.
- **📷 3 Custom Photo Placements**:
  - *Hero Section*: Solar disc portrait frame.
  - *About Me Section*: Vertical framed photo in front of the *Faculty of Computers & Information (Assiut University)*.
  - *Experience Section*: Desert sunset portrait embedded in the Engineering Philosophy spotlight banner.
- **💼 Recruiter-Friendly Experience Timeline**: Detailed career track covering roles at Wadi Degla Clubs and Ejada Systems.
- **💻 Interactive Projects Showcase**: Category filterable cards (*All*, *.NET & Backend*, *Full Stack & AI*, *Web Applications*) with modal popups for deep technical specs.
- **🛠️ Categorized Skills Architecture**: Clean skill badges organized into 6 core categories (Backend, CRM, Frontend, Databases, Tools, Fundamentals) without fake percentage bars.
- **✉️ Asynchronous Contact Form**: Powered by **Formspree AJAX API** (`fetch()`) with custom success and error toast notifications.
- **📱 Fully Responsive**: Optimized for ultra-fast load times, mobile devices, tablets, and desktop displays.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System & CSS Custom Variables), Vanilla JavaScript (ES6+ Fetch API).
- **Typography**: Google Fonts ([Cinzel](https://fonts.google.com/specimen/Cinzel) for regal headings, [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) for body text, [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) for code chips).
- **Icons**: Phosphor Icons library.
- **Form Backend**: Formspree AJAX Service.
